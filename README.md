# Project_Biblio
# Web Catalog System for Libraries

An interactive web interface developed for searching and browsing library catalogs, built as part of my final front-end development project.

# Technologies Used
* **HTML5:** Semantic structure of the site.
* **CSS3:** Responsive design, layout, and visual styles.
* **JavaScript (ES6+):** Interactive logic for dynamic book search, real-time filtering, and user interface management.

# Key Features
* **Real-time search:** Allows users to instantly find books by title, author, or category.
* **Responsive design:** Optimized for proper display on both mobile devices and desktop computers.
* **DOM interactivity:** Dynamic manipulation of elements to display book details.
